# Добавлены тесты для отладки функций модуля `Geometrci lib`
## Что затрагивают тесты
Тесты покрывают все функции всех 4 реализованных на данный момент абстрактных фигур (по 2 функции на каждый вид фигуры)
## Структура
### circle.py
всего 12 тестов:
#### area
```
нормальные значения - 2 теста
нулевой радиус - 1 тест
большие значения - 2 теста
отрицательные значения - 1 тест
```
#### perimeter
```
нормальные значения - 2 теста
нулевой радиус - 1 тест
большие значения - 2 теста
отрицательные значения - 1 тест
```
### rectangle.py
всего 18 тестов:
#### area
```
нормальные значения - 2 теста
квадрат - 2 теста
нулевые стороны - 3 теста
большие значения - 3 теста
отрицательные значения - 1 тест
```
#### perimeter
```
нормальные значения - 2 теста
квадрат - 2 теста
нулевой периметр - 1 тест
большие значения - 1 тест
отрицательные значения - 1 тест
```
### square.py
