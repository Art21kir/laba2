# Документация к модулю `geometric_lib`
## Общее описание решения
Модуль `geometric_lib` предназначен для работы в контексте двумерных простых геометрических фигур, собой представляет библиотеку для языка **Python**. Модуль умеет работать с абстрактными геометрическимим примитивами.
В текущей версии модуля реализована работа с такими фигурами, как:
```
- Прямоугольник
- Квадрат
- Треугольник
- Круг
```
## Описание всех функций
### Square.py
Данный `.py` файл содержит в себе реализацию двух функций для работы с астрактным квадратом, а именно:
#### area
Функция для получения численного значения площади абстрактного квадрата.
##### Аргументы
```
a <int|float> - численное значение длины стороны абстрактного квадрата
```
##### Возвращаемые значения
```
a * a <int|float> - численное значение площади абстрактного квадрата с указанной стороной
```
##### Реализация
```py
def area(a):
    '''принимает в качестве аргумента сторону квадрата a и возвращает
    площадь этого квадрата'''
    return a * a
```
#### perimeter
Функция для получения численного значения периметра абстрактного квадрата.
##### Аргументы
```
a <int|float> - численное значение длины стороны абстрактного квадрата
```
##### Возвращаемые значения
```
a * 4 <int|float> - численное значение периметра абстрактного квадрата с указанной стороной
```
##### Реализация
```py
def perimeter(a):
    '''принимает в качестве аргумента сторону квадрата a и возвращает
    периметр этого квадрата'''
    return 4 * a
```
### Rectangle.py
Данный `.py` файл содержит в себе реализацию двух функций для работы с астрактным прямоугольником, а именно:
#### area
Функция для получения численного значения площади абстрактного прямоугольника.
##### Аргументы
```
a <int|float> - численное значение длины 1-ой стороны абстрактного прямоугольника
b <int|float> - численное значение длины 2-ой стороны абстрактного прямоугольника
```
##### Возвращаемые значения
```
a * b <int|float> - численное значение площади абстрактного прямоугольника с указанными сторонами
```
##### Реализация
```py
def area(a, b):
    '''принимает в качестве аргумента стороны прямоугольника a, b
    и возвращает площадь этого прямоугольника'''
    return a * b
```
#### perimeter
Функция для получения численного значения периметра абстрактного прямоугольника.
##### Аргументы
```
a <int|float> - численное значение длины 1-ой стороны абстрактного прямоугольника
b <int|float> - численное значение длины 2-ой стороны абстрактного прямоугольника
```
##### Возвращаемые значения
```
(a + b) * 2 <int|float> - численное значение периметра абстрактного прямоугольника с указанными сторонами
```
##### Реализация
```py
def perimeter(a, b):
    '''принимает в качестве аргумента стороны прямоугольника a, b
    и возвращает периметр этого прямоугольника'''
    return 2 * (a +  b)
```
### Circle.py
**Для работы необходим встроенный модуль `math`.**
Данный `.py` файл содержит в себе реализацию двух функций для работы с астрактным кругом, а именно: 
#### area
Функция для получения численного значения площади абстрактного круга.
##### Аргументы
```
a <int|float> - численное значение радиуса абстрактного круга
```
##### Возвращаемые значения
```
pi * a * a <int|float> - численное значение площади абстрактного круга с указанным радиусом
```
##### Реализация
```py
def area(r):
    '''принимает в качестве аргумента радиус окружности r и возвращает
    площадь этой окружности'''
    return math.pi * r * r
```
#### perimeter
Функция для получения численного значения длины окружности абстрактного круга.
##### Аргументы
```
a <int|float> - численное значение радиуса абстрактного круга
```
##### Возвращаемые значения
```
pi * a * 2 <int|float> - численное значение длины окружности абстрактного круга с указанным радиусом
```
##### Реализация
```py
def perimeter(r):
    '''принимает в качестве аргумента радиус окружности r и возвращает
    длинну этой окружности'''
    return 2 * math.pi * r
```
### Triangle.py
Данный `.py` файл содержит в себе реализацию двух функций для работы с астрактным треугольником, а именно:
#### area
Функция для получения численного значения площади абстрактного треугольника.
##### Аргументы
```
a <int|float> - численное значение длины стороны абстрактного треугольника
h <int|float> - численное значение высоты абстрактного треугольника, проведённой к указанной стороне
```
##### Возвращаемые значения
```
a * h * 1/2 <int|float> - численное значение площади абстрактного треугольника с указанной стороной
```
##### Реализация
```py
def area(a, h):
    '''принимает в качестве аргумента сторону a, высоту h треугольника
    и возвращает площадь этого треугольника'''
```
#### perimeter
Функция для получения численного значения периметра абстрактного треугольника.
##### Аргументы
```
a <int|float> - численное значение длины 1-ой стороны абстрактного треугольника
b <int|float> - численное значение длины 2-ой стороны абстрактного треугольника
c <int|float> - численное значение длины 3-ей стороны абстрактного треугольника
```
##### Возвращаемые значения
```
a + b + c <int|float> - численное значение периметра абстрактного треугольника с указанной стороной
```
##### Реализация
```py
def perimeter(a, b, c):
    '''принимает в качестве аргумента стороны a, b, c треугольника
    и возвращает периметр этого треугольника'''
    return a + b + c
```
